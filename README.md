# Exploring GAN Variants for Balancing Imbalanced Datasets

## Project Overview
This project investigates the use of Generative Adversarial Networks (GANs) to solve the problem of class imbalance in fraud detection datasets.

Two GAN models were implemented:
- Vanilla GAN
- Wasserstein GAN (WGAN)

Synthetic fraud samples generated by these models were added to the original dataset in order to improve classification performance.

---

## Dataset Description
The dataset contains financial transaction records labeled as either fraudulent or non-fraudulent transactions.

The dataset is highly imbalanced:
- Majority class: Normal transactions
- Minority class: Fraud transactions

---

## Project Workflow

1. Data loading and preprocessing  
2. Imbalance analysis and visualization  
3. Vanilla GAN implementation and training  
4. WGAN implementation and training  
5. Synthetic fraud sample generation  
6. Dataset balancing using generated samples  
7. Classification model training  
8. Performance evaluation and comparison

---

## Results
The use of GAN-generated fraud samples improved fraud detection performance compared to the original imbalanced dataset.

Both Vanilla GAN and WGAN improved Recall and F1-Score significantly.
